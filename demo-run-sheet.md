# Demo Run Sheet — 5:00 hard limit

## 0:00–0:45 — Framing

- **Thesis, one breath:** personalization worked because it was expensive. AI made writing
  cheap, so the cost moved to **judgment** — which signal to lead with, and admitting when
  the evidence is thin.
- **Product, one line:** name + company in → it researches, ranks, drafts, verifies. **It never sends.**
- Point at the pipeline on screen as you say it: **retrieve → rank → draft → verify.**
- Do NOT: open Settings, name providers, mention YAML.

## 0:45–3:00 — Devin Weil run

- **Start the run first, then talk.** Dead air is the enemy.
- While it runs: free sources fire first; paid rungs only if the free ones come back thin.
- **When cards land — don't read them.** Pick one, say why it won and what it beat.
  - *The ranking is the product. The email is just the output.*
- **On the draft:** read **one** line — the hook. Then point at:
  - the claim-strength label
  - the source link
- Say it: *"every sentence traces to a source; the verifier runs after the model, not inside the prompt."*
- If it degrades — say so out loud, treat it as the feature.
  - *"It told me the evidence was company-only instead of pretending it was personal."*

## 3:00–3:20 — Edge cases (the bridge)

> Say as one block, then move straight to the artifact.

- *"The interesting part isn't the happy path, it's the edges. Three kinds:"*
  - **Relevant but unusable** — layoffs, bereavement, litigation. Caught by guardrails, not by
    hoping the model has taste.
  - **Failed vs. empty** — identical if you're careless, opposite meanings: *no signal* vs.
    *we didn't look.*
  - **Thin evidence** — honest answer is company-level, not personal. Says so on the face of
    the output instead of inventing a detail.
- Land the number: **"N cases handled — and each one degrades instead of failing."**
  - Have N ready. Say the number, not "a bunch."
  - If the artifact lists them, point at the list — don't read it.

## 3:20–4:30 — Artifact, the numbers

- Transition: *"That's one run. Here's what it means at volume."*
- Economics as a **comparison**, not a spec sheet: cost/prospect and time/prospect vs. a human
  SDR doing the same research. **One number each.** Don't walk the table.
- Gap-filler point: paid sources fire only when free ones fail → average cost well under worst case.

## 4:30–5:00 — Close

- One line: where it goes next (orchestration, volume).
- One line: the boundary — **human reviews and sends, always.**
- Stop talking. No summary.

---

## Emphasize

- **Judgment over generation.** Say *"it decided"* more than *"it wrote."*
- **Honest degradation.** A stated weak claim beats a confident wrong one.
- **The verifier is deterministic and non-negotiable.**

## Avoid

- Providers, fallback chains, YAML, tier system, test counts. Nobody asked.
- Reading generated text aloud beyond one line.
- Apologising for anything slow or thin — narrate it as designed behaviour.

## If over time — cut in this order

1. The "where it goes next" line at the close.
2. Economics down to a single number.

## If under 4:00 — optional strongest moment

- 10-second second run on a deliberately bad input (gibberish company, or a prospect with no
  footprint). Let it degrade gracefully on screen.
